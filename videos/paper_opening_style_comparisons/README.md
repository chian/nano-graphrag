# Paper-Guided Opening Style Comparisons

Six comparison videos that reinterpret GASL openings using the six cinematic opening styles described in the CHI 2022 paper on data-video openings.

- `paper-symbolism-metaphor.mp4` — Paper Style · Symbolism & Metaphor
- `paper-camera-eye.mp4` — Paper Style · Camera Eye
- `paper-creative-sound.mp4` — Paper Style · Creative Sound
- `paper-big-bang.mp4` — Paper Style · Big Bang
- `paper-old-footage.mp4` — Paper Style · Old Footage
- `paper-ending-first.mp4` — Paper Style · Ending First
